# Artifacts Directory

Folder ini berisi output generated dari eksperimen.

- `features/`: extracted CNN feature vectors.
- `weights/cnn/`: bobot model CNN.
- `weights/captioning/`: bobot decoder RNN/LSTM.
- `histories/`: training history.
- `predictions/`: hasil prediksi/inference.
- `plots/`: grafik loss, metric, dan visualisasi.

Isi generated artifacts tidak di-commit.
